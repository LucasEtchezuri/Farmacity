Política de Privacidad – Sensiva Última actualización: 12/03/2026 Sensiva es una aplicación desarrollada para el monitoreo remoto de temperatura y condiciones ambientales en equipos de refrigeración utilizados para el almacenamiento de productos farmacéuticos. Esta Política de Privacidad describe cómo recopilamos, utilizamos y protegemos la información cuando utilizas la aplicación Sensiva. 1. Información que recopilamos La aplicación Sensiva puede recopilar y procesar los siguientes tipos de información: Información de la cuenta Para utilizar la aplicación, los usuarios pueden necesitar autenticarse mediante credenciales proporcionadas por su organización. Esto puede incluir: dirección de correo electrónico identificador de usuario credenciales de acceso Datos de dispositivos monitoreados La aplicación muestra información proveniente de dispositivos IoT instalados en equipos de refrigeración. Estos datos pueden incluir: temperatura humedad (si aplica) estado de alimentación eléctrica identificador del dispositivo marca temporal de mediciones Estos datos son generados por sensores y enviados a la plataforma de monitoreo. Información técnica Podemos recopilar información técnica limitada necesaria para el funcionamiento de la aplicación, como: modelo del dispositivo versión del sistema operativo información de diagnóstico en caso de errores 2. Uso de la información La información recopilada se utiliza exclusivamente para: permitir el acceso a la aplicación mostrar datos de monitoreo de dispositivos IoT generar alertas cuando se superan umbrales de temperatura mantener el funcionamiento y seguridad del sistema mejorar la estabilidad y rendimiento de la aplicación 3. Compartición de información Sensiva no vende ni comparte datos personales con terceros. La información solo puede ser accesible por: la organización que utiliza el sistema el proveedor del servicio Sensiva para fines de operación y soporte técnico 4. Seguridad de los datos Tomamos medidas técnicas y organizativas para proteger la información contra: acceso no autorizado pérdida uso indebido Las comunicaciones entre la aplicación y los servidores se realizan mediante conexiones seguras. 5. Retención de datos Los datos se conservan únicamente durante el tiempo necesario para la operación del sistema de monitoreo y de acuerdo con las políticas de la organización que utiliza Sensiva. 6. Permisos de la aplicación La aplicación puede solicitar acceso a ciertas funciones del dispositivo únicamente cuando sea necesario para su funcionamiento, como acceso a internet para la comunicación con los servidores. Sensiva no accede a datos personales del usuario como contactos, fotos o ubicación. 7. Derechos del usuario Los usuarios pueden solicitar información sobre sus datos o solicitar su eliminación a través del contacto indicado más abajo. 8. Cambios en esta política Podemos actualizar esta Política de Privacidad ocasionalmente. Cualquier cambio será publicado en esta misma página. 9.
