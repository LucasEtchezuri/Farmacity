Política de Privacidad – Sensiva

Última actualización: 12/03/2026

Sensiva es una aplicación desarrollada para el monitoreo remoto de temperatura y condiciones ambientales en equipos de refrigeración utilizados para el almacenamiento de productos farmacéuticos.

Esta Política de Privacidad describe cómo recopilamos, utilizamos y protegemos la información cuando utilizas la aplicación Sensiva.

1. Información que recopilamos

La aplicación Sensiva puede recopilar y procesar los siguientes tipos de información:

Información de la cuenta
  • Dirección de correo electrónico
  • Identificador de usuario
  • Credenciales de acceso
Datos de dispositivos monitoreados
  • Temperatura
  • Humedad (si aplica)
  • Estado de alimentación eléctrica
  • Identificador del dispositivo
  • Marca temporal de las mediciones

Estos datos son generados por sensores IoT y enviados a la plataforma de monitoreo.

Información técnica
  • Modelo del dispositivo
  • Versión del sistema operativo
  • Información de diagnóstico en caso de errores

2. Uso de la información

La información recopilada se utiliza exclusivamente para:

  • Permitir el acceso a la aplicación
  • Mostrar datos de monitoreo de dispositivos IoT
  • Generar alertas cuando se superan umbrales de temperatura
  • Mantener el funcionamiento y seguridad del sistema
  • Mejorar la estabilidad y rendimiento de la aplicación

3. Compartición de información

Sensiva no vende ni comparte datos personales con terceros.

La información solo puede ser accesible por:

  • La organización que utiliza el sistema
  • El proveedor del servicio Sensiva para fines de operación y soporte técnico

4. Seguridad de los datos

Tomamos medidas técnicas y organizativas para proteger la información contra:

  • Acceso no autorizado
  • Pérdida de datos
  • Uso indebido de la información

Las comunicaciones entre la aplicación y los servidores se realizan mediante conexiones seguras.

5. Retención de datos

Los datos se conservan únicamente durante el tiempo necesario para la operación del sistema de monitoreo y de acuerdo con las políticas de la organización que utiliza Sensiva.

6. Permisos de la aplicación

La aplicación puede solicitar acceso a ciertas funciones del dispositivo únicamente cuando sea necesario para su funcionamiento, como el acceso a internet para comunicarse con los servidores.

Sensiva no accede a datos personales del usuario como contactos, fotos o ubicación.

7. Derechos del usuario

Los usuarios pueden solicitar información sobre sus datos o solicitar su eliminación a través del contacto indicado más abajo.

8. Cambios en esta política

Podemos actualizar esta Política de Privacidad ocasionalmente. Cualquier cambio será publicado en esta misma página.
